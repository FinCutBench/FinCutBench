# FinCutBench

**FinCutBench: A Continually Updated Benchmark for Measuring the Temporal Boundaries of LLM Financial Knowledge**

FinCutBench is a continually updated benchmark for assessing the temporal boundaries of financial knowledge in large language models. It currently comprises 9,000 multiple-choice questions spanning 45 months across Chinese and US financial markets.
